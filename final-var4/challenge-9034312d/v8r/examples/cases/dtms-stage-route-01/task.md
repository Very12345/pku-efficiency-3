# 题集 C-2 · CRISPRi 全基因组筛选四阶段技术路线图（合成案例）

> ⚠ **本文件是合成案例，不是组织方固定案例**。材料为演示绘图接口而虚构，
> 不含任何预制答案；正式案例、白板与评分由平台提供/执行。
> 本案例的定位是**阶段路线**类：四个阶段、两个里程碑、一条返工回流、一条数据产物流，
> 用来检验"阶段目标 / 里程碑 / 依赖方向 / 步骤编号与正文逐条对照"四件事。

## 任务

依据 §2–§5 的研究内容，绘制**技术路线图**（`figure_type=route`），要求：

1. 四个阶段分列，阶段边界与阶段名与正文一致；
2. 阶段内的步骤给出**与正文顺序一致的连续编号**（编号错位即判不合格）；
3. 两个里程碑单独标出，且**里程碑是阶段的出口**（不得画成普通步骤）；
4. 里程碑到下一阶段首步之间是**依赖**关系（不是顺序关系）；
5. 返工路径（病毒滴度不足重做包装）用**回流**标识，并指向它真正回到的那一步；
6. 数据产物流（计数矩阵）与候选基因清单都是**终点**，不继续向别处流；
7. 每个图面实体保留材料出处（`source`），交付可编辑 SVG 源文件与 PNG/PDF 预览。

## 材料（虚构）

### §2 阶段一 · 建库

- **§2.1** 设计覆盖全基因组的 sgRNA 文库（每条基因 4–6 条 sgRNA）。
- **§2.2** 克隆入慢病毒载体，电转感受态细胞后扩增文库质粒。
- **§2.3** 三质粒系统共转染包装**慢病毒**；滴度不足时需要**重做包装**（回到本步重来）。
- **§2.4** 测序评估文库丰度均一性（≥ 90% 的 sgRNA 落在 10 倍丰度区间内），
  通过后**放行为里程碑 1**，文库可用于感染。

### §3 阶段二 · 筛选

- **§3.1** 以 MOI 0.3 感染目标细胞系，保证单拷贝整合（感染率 ≤ 30%）。
- **§3.2** 抗生素筛选 7 天，建立稳定表达 Cas9 与 sgRNA 的细胞库。
- **§3.3** 施加功能压力选择（药物处理，IC₅₀ 附近剂量，持续 14 天）。
- **§3.4** 收集存活细胞并扩增，当富集度达到测序要求时记**里程碑 2**。

### §4 阶段三 · 测序

- **§4.1** 提取基因组 DNA，PCR 扩增 sgRNA 区域（每个样本 ≥ 300 万 reads 覆盖）。
- **§4.2** 双端 150 bp 高通量测序。
- **§4.3** 质控、比对与 sgRNA 计数，产出**测序原始数据与计数矩阵**。

### §5 阶段四 · 分析

- **§5.1** 计算 sgRNA 丰度变化（处理组 / 对照组），做标准化与批次校正。
- **§5.2** 基因层面聚合打分，排序并去假阳性，输出**候选靶基因清单**。
- **§5.3** 对排序靠前的候选基因做正交实验验证（独立 sgRNA + 表型复测）。

## 输入形态（给绘制方看的）

- 结构化输入：同目录 `case.json`（18 实体 / 18 关系，含 14 个 `step`、2 个 `milestone`、
  1 个 `product`、1 个 `data`；`sequence` 用于阶段内步骤，`depend` 用于里程碑 → 下一阶段，
  `causation` 用于"产出数据/清单"，`recycle` 用于返工）；
- 文本表单形态：`case.json` 的 `text` 字段（会走文本解构，**里程碑与回流会丢**，
  正是本题要考的四件事，不推荐只用它）。
