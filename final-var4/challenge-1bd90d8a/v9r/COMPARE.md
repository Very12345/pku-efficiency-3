# COMPARE.md — 对照方案（v9 缺依赖降级链轴）

题面要求「使用增益」可验证。本文件说明本包提供的对照证据，以及哪些必须由平台提供。

## 1. 本包能提供的对照：同一份输入、五种环境条件

| 条件 | 做法 | 关注量 |
|-|-|-|
| C0 完整环境 | 不做任何拦截 | 基线：11 个产物、`result.json` 29 键、`status=completed` |
| C1 缺单包 | 逐个拦掉 13 个第三方模块 | 产物集合与 sha256 是否与 C0 一致 |
| C2 只有标准库 | 一次性拦掉全部第三方模块 | 还剩什么、`status` 变什么、退出码 |
| C3 收窄 PATH | PATH 只留解释器目录 | 稳定产物是否与 C0 逐字节一致 |
| C4 假 CLI 陷阱 | PATH 前置 20 个会写日志的假 CLI | 调用日志条数 |

实测结论（本机 Windows + Python 3.13.9）：

| 条件 | 结果 |
|-|-|
| C1（12/13 个模块） | **与 C0 逐字节一致**（0 次拦截记录 ⇒ 压根没被 import） |
| C1（PIL） | exit 1 / `status=failed` / `result.json` 29→**6 键** / 丢 5 个产物 |
| C2 | 与「缺 PIL」完全同构（唯一硬依赖就是 Pillow） |
| C3 | 只有两个 PNG 变（根因 = PATH 解析到的 FreeType，见 `references/DEGRADE-MATRIX.md` §5.1） |
| C4 | 调用日志 **0 条**（阳性对照已验证陷阱能触发） |

## 2. 与「不加载 Skill 的基础 Agent」的对照口径（供组织方白板使用）

本包不提供自己的白板结果（题面禁止提交预制答案或正式案例输出）。它提供的是**可复用的判据**：

| 比较维度 | 可机器判定的量 | 来自 |
|-|-|-|
| 最小可用环境 | 各环境档的 exit/status/产物数/键数 | `degrade_probe.py --json` |
| 是否依赖外部 CLI | 假 CLI 调用次数 + 静态调用点计数 | 同上 `cli_evidence` |
| 缺件时是否诚实 | `status` 与实际产物是否自洽（G8） | `figcheck.py --json` |
| 结果信封是否完整 | `result.json` 顶层键数与契约字段 | `check_contract.py --json` |

同一组命令对任何做法都成立，所以对照公平（同输入、同数据版本、同导出参数）。

## 3. 本包内部的三方对照（结构层面）

| 文件 | 角色 | 本版是否改动 |
|-|-|-|
| `scripts/*.py`（10 个既有入口） | 算法与 CLI 接口 | **逐字节不变** |
| `scripts/degrade_probe.py` | 本版新增的降级链实测台 | 新增 |
| `references/*.md`（既有 6 份） | 契约、评分映射、失败模式等 | 逐字节不变 |
| `references/DEGRADE-MATRIX.md` | 本版新增：17 档逐项实测 + 最小可用环境清单 | 新增 |
| `degrade_probe_report.json` | 本版新增：机器可读实测证据 | 新增 |

## 4. 诚实的边界

- 本包没有「不加载 Skill 的基础 Agent」的运行记录，也不伪造一份。
- 环境条件是**模拟**的（受控导入拦截 / PATH 收窄 / 假 CLI），不是真的卸载软件包；
  但对被测代码而言与"真的没装"等价，且每次拦截都有 `(module, frame)` 记录可查。
- 缺 PIL 时的不优雅降级（SVG 已产出却从 `outputs` 消失）是**登记在案的缺陷**，
  本文件不把它写成"已优雅处理"。
