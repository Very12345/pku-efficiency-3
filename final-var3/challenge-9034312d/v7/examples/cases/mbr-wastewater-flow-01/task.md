# 题集 C-1 · 市政污水 MBR 工段物质流向图（合成案例）

> ⚠ **本文件是合成案例，不是组织方固定案例**。材料为演示绘图接口而虚构，
> 不含任何预制答案；正式案例、白板与评分由平台提供/执行。
> 本案例的定位是**物质流向**类：一条主链 + 两侧支路（栅渣、剩余污泥）+ 一条回流
> + 一出水分两路，用来检验"分流 / 合流 / 回流 / 废料出口"四件事能不能画对。

## 任务

依据下面 §1–§3 的工艺描述，绘制该工段的**物质流向图**（`figure_type=flow`），要求：

1. 主链顺序与工段划分（预处理 → 生化处理 → 出水）与正文一致；
2. 每个设备的进出物料方向正确，**不得出现方向相反的箭头**；
3. 两条废料支路（栅渣、剩余污泥）各自作为终点，不继续流向别处；
4. 污泥回流单独标识（虚线），并说明回流的目标单元；
5. 出水分两路（达标排放 / 中水回用）都要画出来，不能只画一路；
6. 每个图面实体保留材料出处（`source`），交付可编辑 SVG 源文件与 PNG/PDF 预览。

## 材料（虚构）

### §1 预处理工段

- **§1.1** 厂区进水经**进水提升泵**提升后送入格栅间，设计流量 2.5 万 m³/d。
- **§1.2** **细格栅除污机**截留毛发与纤维类杂物，**栅渣**由螺旋输送机外运处置；
  过栅出水自流进入下一单元。
- **§1.3** **调节池**均衡水量水质，停留时间 6 h，池内设潜水搅拌器。

### §2 生化处理工段

- **§2.1** 调节池出水进入**缺氧池**（反硝化区），停留时间 2.5 h。
- **§2.2** 缺氧池出水进入 **MBR 膜池**；膜池底部由**鼓风曝气机组**连续供气，
  维持溶解氧 2.0–3.0 mg/L，膜通量 18 L/(m²·h)。
- **§2.3** 膜池污泥经**污泥回流泵**回流至缺氧池，回流比 300%；
  剩余污泥从膜池排出后外运处置。

### §3 出水工段

- **§3.1** 膜池出水（已由膜组件截留悬浮物）进入**紫外消毒渠**，剂量 ≥ 25 mJ/cm²。
- **§3.2** 消毒后**达标排放水**排入受纳水体；排放口设在线监测，**在线水质监测记录**
  含 COD、氨氮、总磷三项指标。
- **§3.3** 部分消毒出水作为**中水回用**，用于厂区绿化与冲洗。

## 输入形态（给绘制方看的）

- 结构化输入：同目录 `case.json`（14 实体 / 14 关系，含 `source` 指向本文件小节号）；
- 也可只用 `case.json` 里的 `text` 字段走文本解构（本案例**不推荐**：
  文本解构只串联相邻步骤，分流与回流会丢，正好是本题要考的四件事）。
