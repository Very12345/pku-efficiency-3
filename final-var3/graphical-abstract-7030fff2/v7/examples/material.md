# 实验记录（示例材料，非正式案例数据）

## 1. 材料与表征
- mPEG-PLA 胶束：粒径 = 95 nm；PDI = 0.12
- CMC = 0.8 mg/L（临界胶束浓度）
- 载药量 = 14.2 %
- 包封率 = 72 %

## 2. 体外释放（透析法，37 °C）
- 释放率 pH 5.5 (48 h) = 85 %
- 释放率 pH 7.4 (48 h) = 18 %

## 3. 细胞实验（MCF-7）
- 细胞存活率 (50 µg/mL) = 18 %
- 半抑制浓度 IC50 ≈ 13.6 µg/mL

## 4. 机制描述
- mPEG-PLA 胶束 -> DOX（阿霉素）(自组装包载)
- DOX（阿霉素）-> 肿瘤组织 (被动靶向递送)
- mPEG-PLA 胶束 -> 肿瘤微环境（低 pH）(pH 响应释放)
- DOX（阿霉素）-> 肿瘤细胞 (内化杀伤)
- DOX（阿霉素）-> 肿瘤细胞 (抑制增殖，负面关系)

## 5. 备注
所有数值为合成示意数据，仅用于接口演示。
