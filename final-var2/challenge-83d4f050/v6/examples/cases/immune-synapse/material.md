# 合成材料（案例 1：免疫突触 TCR 近膜信号）

> **本例为 Skill 自带的合成案例（非平台正式案例）**。真实案例的材料由组织方提供；
> 本文件只用于演示"实体 / 关系 / 区室 / 图例"四要素在同一套流水线上的处理，
> 以及"材料未给数值时不得编造数据编码"这一条规则的执行。

## 实体表

| 名称 | 类型 | 区室 | 备注 |
| MHC–肽复合物 | 复合物 | 胞外 | 抗原提呈细胞表面，被 TCR 识别 |
| TCR–CD3 复合物 | 复合物 | 细胞膜 | 跨膜受体复合物，含 CD3ζ 胞内段（ITAM） |
| LCK | 蛋白质 | 细胞膜 | 近膜 Src 家族激酶，磷酸化 ITAM |
| ZAP70 | 蛋白质 | 细胞质 | 被募集到磷酸化 ITAM 的 Syk 家族激酶 |
| LAT | 蛋白质 | 细胞膜 | 跨膜支架蛋白，形成信号体 |
| PLCγ1 | 蛋白质 | 细胞质 | 被 ZAP70/LAT 招募并激活 |
| IP3 | 小分子 | 细胞质 | PLCγ1 水解 PIP2 的产物，触发钙释放 |
| 钙离子 | 小分子 | 细胞质 | 由 IP3 触发的胞内钙升高 |
| 钙调磷酸酶 | 蛋白质 | 细胞质 | 钙依赖磷酸酶，去磷酸化 NFAT |
| NFAT | 蛋白质 | 细胞质 | 转录因子，去磷酸化后暴露入核信号 |
| 核内 NFAT | 蛋白质 | 细胞核 | NFAT 入核形式，与胞质 NFAT 为同一蛋白 |
| SHP-1 | 蛋白质 | 细胞质 | 磷酸酶，负反馈抑制 ZAP70 |

## 关系（箭头语义）

- MHC–肽复合物 结合 TCR–CD3 复合物（强）
- LCK 磷酸化 TCR–CD3 复合物（强，修饰 ITAM）
- ZAP70 结合 TCR–CD3 复合物（强，经 ITAM 募集）
- ZAP70 激活 LAT（强）
- LAT 募集 PLCγ1（强，结合）
- PLCγ1 激活 IP3（强）
- IP3 促进 钙离子（强，钙释放）
- 钙离子 激活 钙调磷酸酶（强）
- 钙调磷酸酶 去磷酸化 NFAT（强，修饰）
- NFAT 转位 核内 NFAT（强，转运入核）
- 核内 NFAT 激活 NFAT（弱，反馈：转录输出回到胞质池）
- SHP-1 抑制 ZAP70（中，负反馈）

## 图面约束

- 信号流向：胞外 → 膜 → 胞质 → 核；受体复合物位于膜带内；负反馈在右侧绕行。
- NFAT 与核内 NFAT 是同一蛋白的两个区室形式，必须拆成两个实体并注明。
