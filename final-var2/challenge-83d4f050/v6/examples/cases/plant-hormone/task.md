# 任务说明（合成案例 2：植物激素与转录后调控）

依据 `material.md` 绘制植物激素信号与转录后调控机制图：

1. **实体与区室**：覆盖 8 个实体；主类型是基因（`ERF1` / `NAC1`）与 RNA（`miR164`），
   不要把基因画成蛋白、也不要把 miRNA 画成蛋白；本案例**没有胞外实体**，不得画空胞外带。
2. **相互作用**：8 条边，包含转录激活（EIN3→ERF1、EIN3→miR164）、
   转录后抑制（miR164→NAC1）、泛素化降解型抑制（EBF1→EIN3，标负反馈）、
   以及 ERF1→ETR1 的弱证据负反馈（虚线）。EIN3 的两条出边必须**并置**，不要串联。
3. **图例与数据编码**：材料给出表达量 0.31–0.88 ⇒ 必须用颜色映射并在图例画色带、标"低 / 高"；
   每个数值都要能定位到材料行。
4. **交付**：可编辑分层 SVG + PNG/PDF 预览 + `model.json` + `result.json`，逐元素标来源。
