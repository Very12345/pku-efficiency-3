# 任务：图神经网络势函数用于固态电解质离子输运模拟 — 学术汇报 PPT（示例）

（示例任务，非正式案例。平台正式案例由组织方提供。）

将给定论文材料组织为一场 **12 页、约 15 分钟**的学术报告，面向计算材料学方向的听众
（组会成员 + 外组旁听），交付可编辑 pptx 及渲染预览，全部内容必须能在材料中定位来源。

## 要求

1. 按「背景与问题 → 方法与数据 → 结果（图/表逐页）→ 讨论 → 局限 → 结论 → 证据映射」组织页面。
2. 每页给出：页级主张、图表编号引用、讲稿/备注（含建议时长）、证据定位（材料行号）。
3. 套用可用模板的母版/版式/占位符；模板缺失时使用 Skill 内置回退模板并如实说明。
4. 图表等比放入容器，不拉伸变形；图号与正文引用保持一致。
5. 交付：
   - `<case_id>_deck.pptx`（可编辑源）；
   - 封面预览 PNG + 幻灯联系表 PNG（如实标注为示意图，非像素级导出）；
   - `result.json`（含全部 output_contract 字段、case_id、status、sources、uncertainty、change_records）。
6. 材料中找不到来源的数值不得编造；缺失部分在 uncertainty 中如实列出。
7. 本案例的 `case.json` 已给出完整的结构化字段，仍应先核对材料行号，再决定每页证据。
