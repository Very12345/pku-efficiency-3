# 任务说明 · 案例 A（湖泊富营养化中试，合成数据）

> 本案例是 Skill 自带的**合成案例**（非平台正式案例）。数据为演示用数值，
> 不代表任何真实湖泊的观测结果。

## 任务

依据 `data.csv`（16 行：4 个处理 × 4 个时间点，每格 n=4）产出**一张双面板图**：

1. **Figure A1（panel）**
   - 面板 A：第 21 天的叶绿素 a 浓度柱状图（4 个处理：Control / N / P / N+P），
     带 **SE** 误差线，并标注 Control 与 N+P 的显著性（`**`，p=0.002，
     来源：双因素方差分析 + Tukey HSD，源表 n=4）。
   - 面板 B：叶绿素 a 随时间（0/7/14/21 天）的变化曲线，按处理分 4 条系列。
2. 轴标签必须带单位（μg/L、d、NTU）。

## 数据与图面约束

- 每个柱子、每个数据点都要能回到 `data.csv` 的列与行（`data-*` 溯源 + `data_manifest.json`）。
- 误差线为 SE（列 `se_chl_a`，单位同 y）。
- 显著性只转述给出的 p 值，不自行计算统计量。
- 处理名以源表原文为准（`Control` / `N` / `P` / `N+P`）。
- 浊度列 `turbidity_NTU` 本案例**不上图**，用于考察"未被引用的源列是否被如实记录"。
- 交付：可编辑分层 SVG + PNG + PDF 预览 + `result.json`（含 output_contract 全部字段）。
