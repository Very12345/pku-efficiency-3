# 任务说明（示例，非正式案例）

材料：`materials/paper-mini.txt`（合成论文 ExampleNet）。
模板：`template-example.pptx`（示例组织方模板；**运行期生成**——
`python "$SKILL_DIR/scripts/make_template.py" --out examples`；未生成时自动回退内置版式）。
受众：研究组组会；时长约 15 分钟；页数上限 8 页。

要求：
1. 提取研究问题、方法、结果和限制，形成页序可讲的叙事主线（不是段落切片）；
2. 每页一个主张，图/表引用与论文编号一致（Fig. 1 / Table 1），数值单位不改写；
3. 在给定模板内排布（占位符约束），源文件可编辑，页脚/配色不被覆盖；
4. 每页写讲解备注（过渡/强调/被问时补充证据），不与页面文字重复；
5. 为每页保留论文定位（p.1–p.4），生成渲染预览并检查；
6. 产出 result.json（含 output_contract 全部字段 + case_id），诚实记录
   状态/来源/不确定性/修改记录。

注意：论文为合成示例。正式评分的 3 个案例由平台提供；本示例只演示接口与流程。
