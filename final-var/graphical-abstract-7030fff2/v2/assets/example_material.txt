# 示例材料（合成，用于演示"数值必须能在材料中找到"）—— 非正式案例

本文件演示 plan/assets 三件套的写法：实体/关系/数据都要能在材料行里定位。
实际案例以平台 /input 下的材料为准。

## 背景

pH 响应型聚合物胶束用于肿瘤药物递送。血液（pH 7.4）中胶束保持稳定，
避免药物提前泄漏；肿瘤微环境（pH 约 5.5–6.5）触发快速释放。

## 方法

- mPEG-PLA 嵌段共聚物自组装包载 DOX（阿霉素）。
- DLS 测定粒径与 PDI；紫外分光光度法测定载药量与包封率。

## 数据

- 粒径: 95 nm
- PDI: 0.12
- 载药量: 14.2 %
- 包封率: 72 %
- 释放率 pH 5.5 (48 h): 85 %
- 释放率 pH 7.4 (48 h): 18 %
- 细胞存活率 (50 µg/mL): 18 %

## 关系示例（A -> B (label)）

mPEG-PLA 胶束 -> DOX（阿霉素）(自组装包载)
DOX（阿霉素） -> 肿瘤组织 (递送)
mPEG-PLA 胶束 -> 肿瘤微环境（低 pH） (pH 响应释放)
DOX（阿霉素） -> 肿瘤细胞 (抑制增殖)
