## 3.1 通路描述（原文摘录，作用于方向判断）

Cytokine **TNF-α** (肿瘤坏死因子 α) 结合其受体 **TNFR1**。
TNFR1 招募衔接蛋白 **TRADD**；TRADD 进一步招募激酶 **RIPK1**。
RIPK1 **激活** 转录因子 **NF-κB**（磷酸化并促进其核转位）。
入核后的 NF-κB **上调** 靶基因 **IL6** 的转录，IL-6 蛋白随即被分泌。

**注意（来源明示的常见误读）**：RIPK1 对 NF-κB 是"激活"，不是抑制；
通路顺序为 TNF-α → TNFR1 → TRADD → RIPK1 → NF-κB → IL6，不可颠倒上下游。

## 3.2 分组（图注对分区的说明）

来源图注把五类分子按功能分为三个模块：
- 「配体-受体模块」：TNF-α、TNFR1；
- 「信号衔接模块」：TRADD、RIPK1；
- 「效应模块」：NF-κB、IL6。

## 3.3 图例要求（图注原文）

图例必须区分三种箭头：实线三角箭头 = 激活 / 促进；
短横 T 型线 = 抑制；虚线箭头 = 转录水平上调。图例不得出现通路中
不存在的箭头类型。
